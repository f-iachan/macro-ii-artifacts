Grau de exposição ao endowment próprio

θ = 0 elimina o risco idiossincrático; θ = 1 preserva toda a exposição da autarquia.
Da partilha completa à autarquia:
share_i = λ_i^(1/σ) / Σ_j λ_j^(1/σ)
c_i,t = (1−θ) · share_i · Y_t + θ · y_i,t
Sob θ = 0, cada agente consome uma fração constante de Y. Para 0 < θ < 1, parte do risco idiossincrático permanece; sob θ = 1, c_i,t = y_i,t.
Interpretação didática: θ é uma interpolação de forma reduzida entre dois benchmarks, não um parâmetro estrutural derivado de um modelo de mercados incompletos. Nesta simulação, b = θ por construção; a igualdade organiza a intuição, mas não deve ser lida como identificação estrutural.

b estimado (coeficiente do endowment individual)
Três referências para interpretar a regressão de Townsend:
• Risk sharing perfeito (mercados completos): b = 0 — o consumo individual só reage ao agregado C_t, não ao endowment próprio y_i,t.
• Partilha incompleta: 0 < b < 1 — nesta interpolação didática, a regressão recupera b = θ por construção.
• Autarquia / hand-to-mouth: α_i = 0 e b = 1 — cada agente simplesmente consome seu próprio endowment.
Na literatura empírica (Townsend, 1994, e réplicas), b estimado costuma ser pequeno mas positivo — evidência de partilha de risco substancial, porém incompleta.
