Nota sobre a transposta. Aqui π é vetor-linha e a regra é πt+1 = πt P. Em muitos livros e códigos, π' aparece como vetor-coluna e a mesma recursão vira π't+1 = P' π't. É a mesma matemática — só troca quem multiplica quem.

2. Diagrama de transições

Cada nó é um estado; cada seta, uma transição de probabilidade positiva (laço = Pii, a chance de ficar no mesmo estado). Espessura e opacidade crescem com a probabilidade, e todas as setas de uma mesma cor saem do mesmo estado — são uma linha de P. As cores dos nós são as do gráfico abaixo.

4. Lendo os quatro casos

Percorra os exemplos e observe o que muda na dinâmica — não como se calcula o alvo (isso fica no notebook). O que interessa aqui é a intuição:

  • Simétrica. Todas as entradas positivas: πt converge para o mesmo π* a partir de qualquer π0. É o caso "bem comportado".
  • Identidade. Ninguém se move: toda distribuição já é invariante. Não há um alvo único — por isso não aparece linha tracejada.
  • Absorvente. O estado 1 é transiente (perde massa e nunca a recebe de volta). Ainda assim πt converge para um π* único, com peso zero no estado transiente: um lembrete de que as hipóteses dos teoremas são suficientes, não necessárias.
  • Periódica. Aqui a convergência quebra: existe um único π* = [0.5, 0.5], mas para π0 ≠ [0.5, 0.5] a cadeia oscila para sempre entre os dois estados. Invariante existir não garante convergir a ela.
