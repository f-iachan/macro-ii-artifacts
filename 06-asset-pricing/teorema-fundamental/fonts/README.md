# Fontes incorporadas

O artefato incorpora as mesmas famílias tipográficas usadas nos slides:

- **Lato Regular/Bold** para o texto;
- **CMU Sans Serif** para a notação matemática composta em HTML.

Os arquivos foram obtidos da distribuição TeX Live 2024 instalada localmente e
convertidos para WOFF2. Lato e CMU Sans Serif são distribuídas sob a SIL Open Font
License 1.1; uma cópia da licença acompanha os arquivos em `OFL.txt`.
