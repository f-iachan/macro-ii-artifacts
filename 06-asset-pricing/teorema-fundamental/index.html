Teorema fundamental do apreçamento — geometria

Ausência de arbitragem ⇔ existência de preços de estado q ≫ 0 com P0′ = q′X.
Complemento interativo dos slides de asset pricing.

Setas do teclado para navegar · nas cenas 3D, arraste para girar.

Ingredientes: ativos, preços, portfólio

Payoffs em t=1: matriz X (|S|×|J|), linhas = estados, colunas = ativos.

X = x11x1j⋯x1|J| xs1xsj⋯xs|J| x|S|1x|S|j⋯x|S||J|

coluna xj: um ativo  ·  linha Xs: um estado

Preços em t=0: P0 ∈ ℝ|J|. Portfólio: θ ∈ ℝ|J|.

Todo portfólio gera um vetor de fluxos de caixa em ℝ|S|+1:

−P0′θ Xθ custo hoje; payoff em cada estado amanhã
É nesse espaço — uma coordenada para hoje, uma por estado — que a geometria do teorema acontece.

O espaço dos fluxos de caixa

arraste para girar

Com |S| = 2 estados, o espaço dos fluxos é ℝ3:

  • fluxo em t=0 (custo, se negativo);
  • payoff em s=1;
  • payoff em s=2.

Cada portfólio θ é um ponto aqui: (−P0′θ, Xθ). O conjunto de todos eles, 𝒷, é um subespaço linear.

Um ativo: 𝒷 é uma reta

arraste para girar

Só o ativo livre de risco (r = 1, preço 1, payoff (1, 1)′): comprar θ unidades gera

θ · (−1, 1, 1)′

𝒷 = a reta azul.

Arbitragem: um θ cujo fluxo tem todas as componentes ≥ 0, com pelo menos uma > 0 — um ponto de 𝒷 dentro do ortante positivo (fora da origem).

Sem arbitragem ⇔ a reta só toca o ortante positivo na origem. Gire a cena e verifique.

Mercados incompletos: vários hiperplanos

arraste para girar

Uma reta em ℝ3 cabe em muitos planos que evitam o ortante positivo.

plano 1, normal z(1) = (1, 1/8, 7/8)′  ⇒  q(1) = (0,125; 0,875)′

plano 2, normal z(2) = (1, 4/5, 1/5)′  ⇒  q(2) = (0,8; 0,2)′

Vários q ≫ 0 apreçam os ativos negociados igualmente bem. Um payoff fora do span (ex.: (1, 0)′) recebe um valor diferente de cada q: 0,125 pelo plano 1, 0,8 pelo plano 2 — um intervalo de preços livres de arbitragem.

Mercados completos: o hiperplano é único

arraste para girar

Entra um ativo de Arrow que paga 1 no estado s=1, com preço 1/2: sua reta é θ(−1/2, 1, 0)′ — com os dois planos antigos ainda em cena.

A nova reta fura os dois candidatos: z(1)·(−½, 1, 0)′ = −3/8 ≠ 0  e  z(2)·(−½, 1, 0)′ = 3/10 ≠ 0. Nenhum contém as trocas novas — os candidatos morrem.

O espaço de trocas cresceu: 𝒷 = span das duas retas = um plano: {(−t/2 − s,  t + s,  s)}.

Um plano em ℝ3 só cabe em um hiperplano: ele mesmo. Mais ativos ⇒ mais trocas possíveis ⇒ menos separadores. O q passa a ser único.

O separador z e os preços de estado

arraste para girar

Separação (Farkas): existe z = (z0, z1, z2)′ ≫ 0 ortogonal a 𝒷.

Aqui: z = (1, 1/2, 1/2)′ — a seta verde, perpendicular ao plano. Confira girando a cena.

qs = zsz0  ⇒  q1 = 0,5,  q2 = 0,5
Cada unidade do ativo j vive em 𝒷: −z0P0j + Σs zsxsj = 0  ⇒  P0′ = q′X com q ≫ 0. Esse é o teorema.

Medida neutra ao risco

Os preços de estado somam o preço do payoff constante 1:

P0f = Σs qs,    Rf = 1P0f

Normalizando q para o simplexo — pesos positivos que somam 1 — nasce uma probabilidade artificial:

πs = qsΣs′ qs′   ⇒   P0j = 𝔼[xj]Rf
Sob π, todo ativo rende o juro livre de risco em média: preço = valor esperado descontado. No exemplo da cena anterior, q = (0,5; 0,5)′ ⇒ π = (0,5; 0,5)′ e Rf = 1.

O essencial da cena 3D em ~10 linhas de Python:

import numpy as np, matplotlib.pyplot as plt
ax = plt.figure().add_subplot(projection='3d')
t = np.linspace(-4, 4, 2)
ax.plot(-t, t, t, lw=3)                        # span do ativo livre de risco
T, S = np.meshgrid(t, t)
ax.plot_surface(-T/2 - S, T + S, S, alpha=.4)  # hiperplano: B com o ativo de Arrow
ax.quiver(0, 0, 0, 1, .5, .5, color='g')       # vetor ortogonal z = (1, 1/2, 1/2)
ax.set_xlabel('fluxo em t=0')
ax.set_ylabel('payoff em s=1'); ax.set_zlabel('payoff em s=2')
plt.show()
